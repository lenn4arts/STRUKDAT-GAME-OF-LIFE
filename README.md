# STRUKDAT-GAME-OF-LIFE
Proyek ini merupakan implementasi dari Conway's Game of Life, sebuah simulasi cellular automaton yang diperkenalkan oleh matematikawan John Horton Conway pada tahun 1970.  Game of Life bukanlah permainan dalam arti tradisional, melainkan simulasi matematika yang menunjukkan bagaimana pola kompleks dapat muncul dari aturan sederhana.
